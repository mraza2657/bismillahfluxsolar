# Bismillah Flux Solar website

Static, responsive, single-page website for Bismillah Flux Solar (proprietor: M. Raza), serving Daska and surrounding areas in Punjab, Pakistan.

## Publish to GitHub Pages (free)
1. Unzip this package.
2. Create a **public** GitHub repository (for example, `bismillah-flux-solar`).
3. Upload **index.html**, **style.css**, **script.js**, and the entire **assets** folder to the repository root (not inside an extra folder).
4. In GitHub, go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**; click **Save**.
6. After deployment, open `https://YOUR-USERNAME.github.io/bismillah-flux-solar/`.

The site requires no build tools or paid hosting. It includes your supplied installation photographs and video. The Google Fonts stylesheet uses an internet connection; fallback fonts are provided. WhatsApp buttons open chat with +92 339 4006880.

## Customize
- Edit headings, services, or contact details in `index.html`.
- Adjust colors and layout in `style.css`.
- Replace the media in `assets/` with your own optimized images or video, keeping the filenames or updating the references.

The website intentionally does not claim certifications, specific equipment specifications, or quantified savings that have not been provided.
